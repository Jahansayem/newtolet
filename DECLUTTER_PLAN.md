| --- | --- | --- | --- | ---: | --- |

| Item | Why it matters | Required? | Safe to remove? | Est. savings | Risk |

## C. Keep
| Item | Why keep | Size impact |
| --- | --- | --- |
| `app/` | Active Next.js route tree | tiny |
| `src/` | Still contains active UI, services, contexts, and route wrappers | tiny |
| `components/` | Active app shell components | tiny |
| `public/` | Runtime assets and service worker | tiny |
| `node_modules` | Needed for local development and validation | moderate |
| `package-lock.json` | Single intended lockfile for npm | tiny |
| `next.config.mjs` | Required Next.js config, including migration alias for `react-router-dom` | tiny |

## Controlled Cleanup Order
1. Remove high-confidence generated output and caches: `.next`, `.next.zip`, `node_modules/.vite`.
2. Update `.gitignore` so generated folders, archives, and cache paths stay out of the repo.
3. Validate the project with a clean `next build`.
4. Remove regenerated `.next` again after validation so the working tree stays decluttered.
5. Leave dependency pruning and legacy-doc cleanup for manual review.
