ROW LEVEL SECURITY (RLS):

Status: ENABLED ✅

Policies Applied:
─────────────────
1. users_insert_own
   Command: INSERT
   Condition: auth.uid() = id
   Purpose: Authenticated users insert their own record

2. users_insert_anonymous
   Command: INSERT
   Condition: auth.uid() = id OR (auth.role() = 'authenticated' AND auth.uid() = id)
   Purpose: Allow newly registered users to insert during signup

3. users_read_own
   Command: SELECT
   Condition: auth.uid() = id
   Purpose: Users can read their own record only

4. users_update_own
   Command: UPDATE
   Condition: auth.uid() = id
   Purpose: Users can update their own record only

5. users_admin_all
   Command: ALL
   Condition: auth.role() = 'service_role'
   Purpose: Service role can perform admin operations
